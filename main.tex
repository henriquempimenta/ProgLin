\subsection[Método de duas fases]{Problemas da forma não padrão: Método de duas fases}
Para resolvermos um problema de programação linear na forma não padrão basta transforma-lo num problema na forma padrão. Um exemplo é o seguinte: minimização de função objetivo, ($\min Z$), um problema equivalente a encontrar seu mínimo é encontrar o máximo de $\max -Z$, porem não é tão obvio quando de trata de restrições do tipo maior ou igual ($\ge$), pois a solução trivial, nem sempre respeita as restrições, para aplicarmo o método, então dividimos em duas fases, a fase I de encontrar uma solução viável e a fase II de otimização.

\subsubsection*{Fase I}
Tome como exemplo a seguinte restrição:

\begin{equation*}
  x_2 + 2x_2 \ge 10
\end{equation*}

Pelo método simplex introduzimos as variáveis de folga:

\begin{equation*}
  s_i = x_1 + 2x_2 - 10
\end{equation*}

Mas nesse caso temos um problema que é, pela solução trivial $s_i < 0$ o que é um absurdo. Para contornarmos esse problema introduzimos as variáveis artificias.

\begin{equation*}
  s_i = x_1 + 2x_2 + a_1 - 10
\end{equation*}

Agora podemos converte a equação para a forma tabular

\section[Problema 1]{Problema na forma não padrão}
Agora vamos usar tudo o que sabemos para resolver o seguinte problema:
\begin{equation*}
    \min Z = 2x_1 + x_2, \qquad\text{s, r} \left\{\begin{matrix}
         x_1 +  x_2 \ge 3 \\
        2x_1 + 3x_2 \ge 9 \\
         x_1        \ge 1 \\
         x_1,  x_2  \ge 0
    \end{matrix}\right.
\end{equation*}
\cleardoublepage

\subsection[Método simplex analítico]{Solução pelo método simplex analítico}
Vamos adicionar variáveis de folga e artificiais, pois o problema está na forma não padrão. Assim, escrevemos:
\begin{align*}
x_1 + x_2 - D_1 + A_1 &= 3 \\
2x_1 + 3x_2 - D_2 + A_2 &= 9 \\
x_1 - D_3 + A_3 &= 1 
\end{align*}

Definimos a função da Fase I:\@

\begin{equation*}
  W = A_1 + A_2 + A_3
\end{equation*}


Substituindo as expressões das artificiais:

\begin{align*}
  A_1 &= 3 - x_1 - x_2 + D_1 \\
  A_2 &= 9 - 2x_1 - 3x_2 + D_2 \\
  A_3 &= 1 - x_1 + D_3
\end{align*}

Logo:

\begin{equation*}
  W = 13 - 4x_1 - 4x_2 + D_1 + D_2 + D_3
\end{equation*}

Como queremos uma solução viável inicial, impomos $A_1 = A_2 = A_3 = 0$:

\textbf{Primeira equação}:
\begin{equation*}
  0 = 3 - x_1 - x_2 + D_1 \quad \Rightarrow \quad x_1 + x_2 - D_1 = 3 \tag{I}
\end{equation*}

\textbf{Segunda equação}:
\begin{equation*}
  0 = 9 - 2x_1 - 3x_2 + D_2 \quad \Rightarrow \quad 2x_1 + 3x_2 - D_2 = 9 \tag{II}
\end{equation*}

\textbf{Terceira equação}:
\begin{equation*}
  0 = 1 - x_1 + D_3 \quad \Rightarrow \quad x_1 - D_3 = 1 \tag{III}
\end{equation*}

Da equação (III):

\begin{equation*}
  x_1 = 1, \quad D_3 = 0
\end{equation*}

Substituindo em (II):

\begin{align*}
  2(1) + 3x_2 - D_2 &= 9\\
  3x_2 - D_2 &= 7 \Rightarrow \\
  x_2 = \frac{7}{3}&,  D_2 = 0
\end{align*}

Substituindo em (I):

\begin{align*}
1 + \frac{7}{3} - D_1 &= 3 \\
D_1 = \frac{4}{3} &\ge 0
\end{align*}

Portanto, a solução básica viável é:

\[
(x_1, x_2, D_1, D_2, D_3) = \left(1,\; \frac{7}{3},\; \frac{4}{3},\; 0,\; 0\right)
\]

A função da Fase I torna-se:

\[
\max(-W) = -2x_1 - x_2
\]

Logo:

\[
\max(-z) = -\frac{13}{3}
\Rightarrow
\min(z) = \frac{13}{3}
\]

onde:

\[
z(1,\, 7/3) = \frac{13}{3}
\]

substituindo em $Z$ temos:

\begin{equation*}
  Z = 10(500 - x_2 - \frac{1}{2}s_3 + \frac{1}{2}s_4) + 12x_2 + 8(500 - x_4 + \frac{1}{2}s_3 + \frac{1}{2}s_4) + 10x_4 = 9000 + 2x_2 + 2x_4 - s_3 + 9s_4
\end{equation*}

Terminada a Fase I, que busca uma solução viável inicial, vem a Fase II que é a de otimização, neste caso  de maximizar $-Z = -9000 - 2x_2 - 2x_4 + s_3 - 9s_4$
